    2 Question

    How a question becomes a number you can trust

    1. Plan and code. on Vultr Serverless Inference plans the checks and writes pandas code.
    2. Contained run. A fresh gVisor container on our Vultr VM: no network, no secrets, read-only inputs, . Destroyed after the run.
    3. Retry. Errors go back to the coder, three attempts at most.
    4. Verify. , a different model family, checks every sentence against the raw output; a sentence with a number not in the output is cut too.
    5. Receipt. Hashes of inputs, code, image and outputs. Re-run it and get the same numbers.

    Pick a question. The answer arrives with the code that produced it, the table, and a receipt.
